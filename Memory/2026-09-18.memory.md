> 项目诞生日:从"调研一下"到双引擎开源产品一天走完。本地引擎 → 菜单栏应用 → 稳定签名 → 双机私域分发 → GitHub 开源 → 云端引擎 → 智能启动与配置指引,全部当日完成并验证。

## 1. 项目在做什么

macOS 全局语音听写工具(Go + CGO):菜单栏常驻,说话自动打进当前聚焦的输入框。双引擎:本地 SenseVoice-Small(离线、恒定 ~100ms、隐私)⇄ 云端百炼 qwen-audio-3.0-asr-flash(英文术语/中英混合/发音容错强,延迟波动)。热键 Ctrl+Option+V 开关听写。开源在 https://github.com/Yx0201/voice-input (MIT),源码分发 + make dist 私域分发双轨。

## 2. 已完成(全部实测验证)

- **本地链路**:malgo 采音 → silero VAD 断句 → SenseVoice int8 识别(M4 Pro 4s/77ms)→ CGEvent 注入。TTS 闭环测试逐字全对标点正确。
- **菜单栏应用**:systray 常驻、双击即用、热键自研 CGEventTap(第三方库在 NSApp 环境事件不投递,已弃用)、麦克风暂停释放。
- **稳定签名体系**(当晚最大坑,已根治):ad-hoc 签名每次编译变指纹→TCC 授权静默失效(面板开着但系统不认)。解法:scripts/make-dev-cert.sh 自签稳定证书 voiceinput-dev(10 年),make app 自动生成+签名,一次授权跨重编译有效。
- **分发**:make dist 产出 VoiceInput-dist.zip(app+模型+非破坏性 Install.command);朋友 M1 机器实测跑通全流程(Gatekeeper「仍要打开」→授权→听写),私域模式成立。
- **首启容错**:模型缺失不再静默退出;任一引擎可用才自动开麦(initBestEngine 自动回退备用引擎);菜单「⬇️ 下载缺失模型」内置下载器(hf-mirror→HF 回退);云端用户只补 1.7MB VAD 免下 228MB 主模型;「❓ 使用帮助」+ 场景化 osascript 指引弹窗(含百炼申请地址一键打开)。
- **云端引擎**:百炼原生多模态接口(input_audio base64);API Key 弹窗输入(osascript 隐藏输入)→ 钥匙串加密存储;引擎菜单热切换(RWMutex)+选择持久化。用户实测验收:英文/混合/发音容错显著强于本地。
- **文档体系**:README(开源品质)+ AGENTS.md + ARCHITECTURE.md + Memory/ + specCoding/(本文件为首份存档)。

## 4. 环境与命令

```bash
# 构建(需要代理,go mod tidy 回退直连 GitHub 会卡死)
nc -z -w 3 127.0.0.1 7897   # 先探活代理
export https_proxy=http://127.0.0.1:7897 http_proxy=http://127.0.0.1:7897
make setup   # 模型三件套 → ~/.voice_input/models(hf-mirror,无需代理)
make app     # 构建+打包+稳定签名(首次可能要钥匙串密码/始终允许)
make dist    # 分发包 zip

# 测试 .app 前必须重新 make app;pkill 后再 open(否则只激活旧实例)
pkill -f "VoiceInput.app/Contents/MacOS"; sleep 1; open VoiceInput.app
tail -f ~/.voice_input/app.log    # 排障第一现场(多实例共享追加)
```

- Go 1.27.1 在 /usr/local/go/bin(非交互 shell 无 PATH);Xcode 许可已授;GOPROXY=goproxy.cn。
- 钥匙串里已有 voiceinput-dev 证书与用户真实百炼 Key(generic-password, service=voice-input)。
- 百炼云端请求**不需要代理**(直连);模型下载走 hf-mirror 直连。
- GitHub 推送走代理(gh 账号 Yx0201)。
